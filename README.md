# Portfolio Data Analyst

Prosta strona statyczna przygotowana do publikacji przez GitHub Pages.

## Publikacja na GitHub Pages

1. Utwórz nowe repozytorium na GitHubie.
2. Prześlij do niego zawartość tego folderu (`index.html`, `styles.css`, `assets`).
3. W ustawieniach repozytorium otwórz **Pages**.
4. Wybierz publikację z głównej gałęzi i folderu głównego (`/root`).

Strona nie wymaga instalowania bibliotek ani uruchamiania komend. Aby zobaczyć ją lokalnie, otwórz `index.html` w przeglądarce.
